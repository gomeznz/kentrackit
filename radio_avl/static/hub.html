One Apple push key for every company, so emergencies reach the KenTrackIt iPhone app with the app closed. In ASI's Apple developer account: Certificates, Identifiers & Profiles → Keys → +, tick Apple Push Notifications service, download the AuthKey_….p8 file (only once) and choose it here.
